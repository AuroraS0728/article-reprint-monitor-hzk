# 第3轮：监测批次、调度和状态矩阵

实现：
1. 立即一次检测批次。
2. 自动检测批次。
3. Celery每小时调度。
4. 周一07:00最后检测。
5. 日报按当天24:00状态冻结。
6. 周报纳入周一07:00最终结果。
7. 状态规则严格执行：
   - 1：成功且发现；
   - 0：成功完成搜索但未发现；
   - —：未检测或失败。
8. 文章—平台状态矩阵。
9. 多链接保留、规范化URL去重、历史成功记录保留。
10. 首次发现时间、最后检测时间、转载发布时间“无”的规则。
11. 后端统一统计：
   - 平台转载率；
   - 检测完成率；
   - 文章转载率。
12. 页面5分钟轮询真实接口，手动刷新不得触发采集。
13. 任务幂等、并发锁、重试和失败日志。

本轮使用假的平台适配器时，只能放在测试/fixture中；正式页面不得显示模拟成功数据。
