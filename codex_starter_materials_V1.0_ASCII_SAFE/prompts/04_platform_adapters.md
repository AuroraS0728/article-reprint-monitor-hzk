# 第4轮：首批5个平台真实适配

在本机完成平台研究和真实验证。

1. 从正式文档和样本确定首批5个平台。
2. 建立统一 `PlatformAdapter` 接口。
3. 建立统一安全HTTP客户端，集中实现：
   - 域名白名单；
   - SSRF防护；
   - DNS rebinding防护；
   - 重定向重校验；
   - 超时；
   - 响应大小限制；
   - 请求日志脱敏。
4. 每个平台按优先级尝试：
   - 公开搜索请求；
   - HTML搜索页；
   - Playwright；
   - 栏目、作者页、RSS或Sitemap。
5. 使用浏览器Network/XHR分析仅作为开发研究手段。
6. 不得绕过登录或验证码。
7. 使用 `samples/known_original_and_reprints.txt` 做已知链接验证。
8. 为每个平台保存脱敏验证记录：
   - 入口；
   - 请求方式；
   - 分页；
   - 标题/链接字段；
   - 成功样本；
   - 失败样本；
   - 最近验证时间。
9. 未验证成功的平台必须标记“待适配/不可确定”，不能伪造成功。

本轮报告每个平台的真实测试结果和证据位置。
