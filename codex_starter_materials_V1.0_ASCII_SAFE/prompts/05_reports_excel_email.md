# 第5轮：日报、周报、Excel和邮件

实现：
1. 日报：
   - 按24:00冻结状态；
   - 后台生成和下载；
   - 不自动发送。
2. 周报：
   - 周一07:30生成；
   - 包含上周原创文章转载表现；
   - 包含上周新发现转载；
   - 历史版本不覆盖。
3. Excel必须参考简洁版样例：
   - 数据；
   - 每个平台独立表；
   - 总统计；
   - 说明；
   - 不制作图表、仪表盘或KPI卡片。
4. 链接必须是真实Excel超链接对象。
5. 统计值由服务端计算，不依赖易产生兼容错误的模板公式。
6. Excel公式注入防护。
7. SMTP配置：
   - 密钥只从后端环境变量或加密配置读取；
   - 测试邮件；
   - 周报自动发送；
   - 失败重试2次；
   - 手动重发；
   - 发送记录。
8. 阅读量V1.0不采集。

增加报表单元测试、邮件mock测试和版本管理测试。
