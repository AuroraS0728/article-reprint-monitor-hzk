# 第2轮：权限、原创文章和平台管理

在第1轮可本机启动且测试通过后执行。

实现：
1. 用户、角色、权限：
   - 管理员；
   - 运营人员；
   - 查看人员；
   - 禁止自助注册。
2. 登录、退出、会话安全、登录失败限制。
3. 原创文章：
   - 手动录入；
   - 编辑；
   - 查询；
   - 批量选择；
   - Excel导入；
   - 重复提示；
   - 历史空白不得解释为状态0。
4. 平台管理：
   - 启用、禁用、归档；
   - 域名白名单；
   - 搜索深度；
   - 超时、重试；
   - 适配方式；
   - 最近验证时间。
5. 审计日志。
6. 前端页面接入真实API，不得使用固定数组或随机数。
7. 权限测试、上传安全测试和API测试。

本轮完成后报告：
- 数据库迁移；
- API清单；
- 页面；
- 测试结果；
- 是否存在mock/写死数据；
- 安全风险。
