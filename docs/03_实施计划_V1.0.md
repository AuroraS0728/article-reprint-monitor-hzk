# 实施计划 V1.0

## 目录与模块

```text
backend/apps/        accounts, articles, platforms, monitoring, reposts, reports, mailer, audit, core
backend/config/      settings, urls, celery
frontend/src/        API client, layout, views, components (无业务 mock)
deploy/nginx/        反向代理与限速
docs/                基线、审查、威胁模型、运行说明
samples/             只放受控样本、脱敏适配证据和测试数据集
```

数据模块按文档划分：accounts（用户/角色）；articles（文章/导入）；platforms（平台、允许域名、配置、健康）；monitoring（批次、快照、轮次、状态）；reposts（链接、观测、人工动作）；reports（文件、生成版本）；mailer（SMTP 配置、发送记录）；audit/system（审计、配置、清理、备份）。所有核心事实采用 Migration 和非物理删除。

## 阶段

1. 骨架（本轮）：配置、认证、角色、Compose、质量工具、威胁模型；无适配器、无模拟业务数据。
2. 领域基础：Migration、RBAC、审计、文章与导入安全、平台配置、批次快照与统计服务测试。
3. 采集安全底座：统一安全请求客户端、SSRF/DNS/重定向测试、适配证据归档机制；完成后才开始单个平台验证。
4. 适配验证：每个平台先保存真实本机证据和固定样本，再实现适配器与回归；失败保持 —。
5. 调度/页面/报表：幂等锁、任务、API、真实数据 Vue 页面、最终确认的 Excel 基线与邮件。
6. 上线准备：24 小时验证、备份恢复、漏洞/密钥扫描、`check --deploy`、UAT、发布与回滚演练。
