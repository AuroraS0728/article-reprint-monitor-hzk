# 威胁建模 V1.0（开发前）

| 威胁 | 攻击面 | 首期控制 | 验证/未关闭项 |
| --- | --- | --- | --- |
| 敏感信息泄露 | `.env`、日志、SMTP、HAR | 环境变量、`.gitignore`、掩码接口、日志禁区 | 仍需密钥扫描和生产权限验证 |
| SSRF / DNS rebinding | 人工 URL、平台 URL、重定向 | 后续统一安全请求客户端：域名白名单、IP 分类阻断、逐跳验证、限端口/超时/大小、禁代理 | 尚未实现；禁止适配器与外部请求 |
| 文件上传 | Excel 导入 | 后续 xlsx+MIME、10MB/1000 行、随机临时名、禁止宏/外链/公式计算 | 尚未实现 |
| Excel 公式注入 | 导出文本 | 后续对 `= + - @` 前置单引号 | 尚未实现 |
| 越权 | REST 写接口、下载 | Session + API 权限；角色模型；后续对象级策略、审计 | 仅认证骨架已实现 |
| XSS / CSRF / SQL 注入 | 标题、备注、表单、查询 | Vue 默认转义、不用 `v-html`；Django CSRF；ORM | 后续输入边界和 CSP 待测 |
| 暴力登录 | 登录接口 | django-axes，5 次/15 分钟 | 集成测试待 Docker 环境 |
| 密钥误提交 | Git/CI | `.env.example` 无真实密钥、pre-commit detect-private-key | pre-commit 和扫描待执行 |
| MySQL/Redis 公网暴露 | Compose/生产网络 | 不映射端口、内部网络、生产安全组要求 | 部署审计待环境就绪 |

安全结论：外部采集、文件导入、报表导出和生产部署均尚未通过安全门禁；不得上线。
