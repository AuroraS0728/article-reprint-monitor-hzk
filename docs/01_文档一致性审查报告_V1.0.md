# 文档一致性审查报告 V1.0

审查日期：2026-08-06。审查范围为根目录可见资料、`docs/` 01--22、`prototype/index.html`、原型截图及 `samples/` 中名为“文章转载监测系统_目标报表样例_V1.0_简洁版.xlsx”的工作簿。根目录未发现 `AGENTS.md`，仓库内也未找到该文件；因此不存在可执行的项目级补充约束。

## 已确认需求

- 栈固定为 Python 3.12、Django 5.2、DRF、Vue 3/TypeScript/Vite、Celery/Beat/Redis、MySQL 8.4、Docker Compose、Nginx；时区 Asia/Shanghai，数据库存 UTC。
- 首期仅 5 个平台：今日头条、搜狐、雪球、百家号、东方财富财富号。仅限公开内容；不绕过登录、验证码、签名或访问控制；没有已完成的本机验证记录。
- 标题经 NFKC、实体/空格/常见标点归一后完全匹配。状态 1=有效命中、0=成功完成规定范围未命中、—=未检测或无法判断；技术失败绝不可写 0。命中历史不能自动回退为 0。
- 批次冻结文章和平台快照；默认每小时运行，到下周一 07:00 最后一轮。日报取每日 24:00，周报从原始数据重算，07:30 生成、08:00 前邮件发送。阅读量明确未启用。
- 平台转载率分母包括失败平台；完成率仅计算状态 1 与 0。历史 Excel 空白均是 UNKNOWN，不能推为 0。
- 三角色为管理员、操作人员、查看人员；不开放注册。所有关键动作审计；管理员才可作废/恢复。

- Excel “目标样例”与完整文档不一致，无法确定最终导出内容和视觉验收。

## 暂定默认值

- 全部外部采集默认禁用；平台配置和适配器均不创建。
- 本机 Docker 仅暴露 API 8000、Vite 5173；MySQL 与 Redis 不映射宿主机端口。Nginx 为可选 profile。
- 登录锁定采用连续 5 次失败、15 分钟；上传限制将在导入模块落地为 xlsx、10 MB、1000 行。
- 首期仅实现 Session + CSRF 同源认证；无公开注册、无 token API。

## 第一阶段风险

- 高：平台可用性和验收指标均依赖尚未建立的固定正/负/异常样本及真实验证记录。
- 高：Excel 验收基线冲突会直接影响数据模型、报表和 UAT。
- 高：DNS rebinding/SSRF 需要统一安全客户端与网络级回归测试后才可启用任何外部请求。
- 中：Docker 首次构建需要下载镜像和依赖；当前环境未验证 Docker/网络可用性。
- 中：生产网络、密钥、邮箱、备份与域名尚未配置，当前骨架绝不可视为上线就绪。
